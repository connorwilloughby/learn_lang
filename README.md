Want to learn a language? Hate paying for subscription services? Are you a nerd?  

This repo can solve two of your three problems. The aim for this project is to get a lightweight tool 

## getting started 

If you have UV installed on your system then you can get stuck in with `sync` then running the entry point below.

```bash
uv sync
uv run -m src.main
```

## language roadmap

Currently the main challenge with language support is the sourcing of standardised data for the various problem types. For the long term the source language will be English.
